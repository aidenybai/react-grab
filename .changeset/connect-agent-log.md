Add **Connect agent** to the toolbar menu. It generates a link to an agent log and copies a prompt for your coding agent. While connected, comments go to the log as todos instead of the clipboard. A tray above the toolbar shows each todo moving from todo to in progress to done, with the agent's notes. The connection persists in localStorage. Set the log server with the new `agentLogServerUrl` option (default `https://agent.react-grab.com`).
